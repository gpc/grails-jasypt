=== Further Documentation

For now, documentation is a little light. There's a https://github.com/gpc/grails-jasypt/tree/6.0.x/examples/sample-hibernate5[sample project] checked in as part of the repository that shows the plugin being used (and has tests that exercise the functionality). The https://github.com/gpc/grails-jasypt/blob/6.0.x/examples/sample-hibernate5/grails-app/domain/com/bloomhealthco/domain/Patient.groovy[Patient domain object] has encrypted `firstName` and `lastName` fields on it.

The https://github.com/gpc/grails-jasypt/tree/6.0.x/examples/sample-hibernate7[Hibernate 7 sample project] runs the same sources and tests on Hibernate 7.
