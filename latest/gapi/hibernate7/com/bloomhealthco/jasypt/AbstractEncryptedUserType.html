      @groovy.transform.CompileStatic
abstract class AbstractEncryptedUserType<T, E>
extends java.lang.Object
implements org.hibernate.usertype.UserType<T>, org.hibernate.usertype.ParameterizedType

      Base class of the Hibernate 7 encrypted user types. The parameters given to the user type are merged with the default parameters from the application config (see com.bloomhealthco.jasypt.JasyptDefaultParameters). The encryptor is created lazily, as encryptors registered by name are registered by Spring after the user types are created.

      Type Parameters:
      T - the type of the mapped property
      E - the type of the jasypt encryptor
