    • com.bloomhealthco.jasypt.JasyptEncryptorParameters 
    • @groovy.transform.CompileStatic
class JasyptEncryptorParameters
extends java.lang.Object

      The encryptor settings of an encrypted user type. Validates and applies the parameters the same way as the jasypt-hibernate5 user types do, so values encrypted with the Hibernate 5 flavour of the plugin can be decrypted by this one.
